# Shenanigans Merch

WooCommerce block theme and WordPress Playground demo for Shenanigans.

[Launch the demo in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fjamiemarsland%2Fshenanigans-merch%2Fmain%2Fblueprint.json)

## Files

- `shenanigans-merch/`: editable theme source.
- `shenanigans-merch.zip`: installable WordPress theme.
- `blueprint.json`: self-contained Playground setup with WooCommerce and a sample variable T-shirt product.
- `demo.php`: demo content setup, used only by Playground.
- `package.py`: rebuilds the ZIP and blueprint from the theme source.

The demo uses placeholder imagery, a GBP 25 price and sizes S to XXL. Checkout is disabled in the demo. Installing the theme ZIP on another WordPress site does not create demo products or disable payments.

The theme and blueprint passed structural checks. A full Playground runtime test has not yet completed in the build environment.

See the theme README for installation details.
