# Shenanigans Merch
A standalone WordPress block theme for a WooCommerce store. No Shopify and no page builder.

## Install
1. On your shop WordPress site, install and activate WooCommerce.
2. Appearance → Themes → Add New → Upload Theme → choose shenanigans-merch.zip, then activate.
3. Set the site title and choose your shop page in WooCommerce settings.
4. Add the real T-shirt as a Variable product. Create a Size attribute (S, M, L, XL, XXL), enable it for variations, then create variations and set each price and stock.
5. Upload the real product image and gallery images. Enter the short description, description and shipping details.
6. Set currency, shipping, tax and payment options before accepting orders.
7. Add a Merch link to shop.shenanigans.band on the main website after the subdomain is connected.

## Editing
Appearance → Editor → Templates → Single Product controls the layout.
Header and footer are editable template parts. Product content lives in Products.
The theme uses WooCommerce's gallery, price, summary, variation form and product details blocks.
Size buttons progressively enhance the native size selector, leaving WooCommerce responsible for stock and variation selection.
WooCommerce supplies the cart and checkout. The theme does not process payments or define shipping policies.

## Preview
The separate Playground blueprint sets up a disposable demo only. Its £25 price, sizes and product copy are placeholders. It must not be used as a production catalogue.
The theme ZIP itself never creates products, orders or customers and never changes payment settings.
Design assets are the existing band font and paper texture.
